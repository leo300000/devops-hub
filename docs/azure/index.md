# ☁️ Azure

> **Le cloud Microsoft — ta salle des machines dans le cloud**

---

## L'analogie parfaite

!!! quote ""
    Azure, c'est louer une **salle des machines** plutôt que d'en construire une.
    Tu paies uniquement ce que tu utilises, tu n'as pas à gérer le hardware, et tu peux scaler en quelques clics.

---

## Azure vs AWS vs GCP

| | Azure | AWS | GCP |
|--|-------|-----|-----|
| **Part de marché** | 23% | 31% | 12% |
| **Points forts** | Entreprises, Microsoft stack | Catalogue, maturité | Data, ML/AI |
| **Gratuit** | 200$ crédits + services gratuits | 300$ crédits | 300$ crédits |
| **Certification** | AZ-900 → AZ-104 | Cloud Practitioner → SAA | ACE → PCA |
| **Kubernetes managé** | AKS | EKS | GKE |
| **Serverless** | Azure Functions | Lambda | Cloud Functions |
| **Stockage objet** | Blob Storage | S3 | GCS |

---

## Les services Azure à connaître

| Catégorie | Service Azure | Équivalent AWS |
|-----------|--------------|----------------|
| **VM** | Virtual Machines | EC2 |
| **Container** | AKS | EKS |
| **Serverless** | Azure Functions | Lambda |
| **BDD relationnelle** | Azure SQL | RDS |
| **BDD NoSQL** | Cosmos DB | DynamoDB |
| **Stockage** | Blob Storage | S3 |
| **Réseau** | VNet | VPC |
| **Secrets** | Key Vault | Secrets Manager |
| **CI/CD** | Azure DevOps | CodePipeline |
| **Monitoring** | Azure Monitor | CloudWatch |
