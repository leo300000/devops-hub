# 🌿 Git

> **La machine à remonter le temps pour ton code**

---

## L'analogie parfaite

!!! quote ""
    Git, c'est comme **Google Docs avec l'historique des versions** — mais pour du code.
    
    Tu peux voir qui a changé quoi, quand, pourquoi — et revenir en arrière à n'importe quel moment.

Sans Git :
```
projet_v1.zip
projet_v2.zip  
projet_v2_FINAL.zip
projet_v2_FINAL_vrai.zip
projet_v2_FINAL_vrai_cette_fois.zip  😱
```

Avec Git :
```bash
git log  # Historique propre de chaque changement
git checkout abc123  # Retour à n'importe quelle version
```
