## GitHub vs GitLab vs Bitbucket

| | GitHub | GitLab | Bitbucket |
|--|--------|--------|-----------|
| **Propriétaire** | Microsoft | GitLab Inc. | Atlassian |
| **Open Source** | Non | Oui (core) | Non |
| **CI/CD natif** | Actions | GitLab CI | Pipelines |
| **Self-hosted** | Enterprise | ✅ Gratuit | ✅ |
| **Popularité** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| **Intégration Jira** | Plugin | Natif | ⭐⭐⭐⭐⭐ Natif |

**→ GitHub = le standard de l'industrie open source.**
