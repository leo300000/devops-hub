## C'est quoi le DevOps ?

!!! quote "En une phrase"
    Le DevOps, c'est **casser le mur** entre les devs qui codent et les ops qui déploient — pour livrer plus vite, plus souvent, avec moins de bugs.

Avant le DevOps :

```
Dev → "C'est prêt !"    Ops → "Ça marche pas chez moi 🤷"
```

Avec le DevOps :

```
Dev + Ops → automatisation → livraison continue → tout le monde est content ✅
```
